# Implantar, associar, instalar o Adobe Commerce Developer Agent

Com tudo conectado, o aplicativo está pronto para produção. Esse estágio implanta o código, associa e instala no administrador do Adobe Commerce para que o novo recurso seja ativado na loja.

## Para quem é este vídeo?

* Desenvolvedores do Commerce
* Arquitetos de soluções
* Administradores do Commerce

## Conteúdo de vídeo

* Pedir ao agente do desenvolvedor para implantar a partir do chat e confirmar a organização, o projeto e o espaço de trabalho exatos
* Uma aprovação de validação pré-implantação e, em seguida, a compilação de transmissão e a saída de publicação conforme o código é implantado
* Associar o aplicativo implantado a uma loja específica na tela Gerenciamento de aplicativos do administrador do Commerce
* Analisar o cartão de aplicativo — nome, versão e os recursos adicionados a ele (um webhook)
* Instalação do aplicativo para ativar o recurso e confirmar se ele foi instalado com êxito
