# Configuração e teste do Adobe Commerce Developer Agent

Depois que o aplicativo é instalado, seus limites e mensagens se tornam configurações comerciais que qualquer pessoa pode ajustar — nenhum código é necessário. Esse estágio configura o limite de quantidade do carrinho e o testa ao vivo na loja para confirmar se a regra funciona.

## Para quem é este vídeo?

* Desenvolvedores do Commerce
* Administradores do Commerce
* Merchandisers

## Conteúdo de vídeo

* Revisão da configuração de negócios que o agente expôs — a quantidade máxima de carrinhos e a mensagem voltada para o comprador
* Redução das unidades máximas do carrinho por SKU, do valor padrão para um valor e economia menores, sem alterações no código
* Adicionar produtos na loja excedendo o limite configurado
* Confirmação do bloco e da mensagem de erro exata, imposição em tempo real sem uma reimplantação
