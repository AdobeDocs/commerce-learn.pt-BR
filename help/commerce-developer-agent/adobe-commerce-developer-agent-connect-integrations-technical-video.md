# Integrações do Adobe Commerce Developer Agent Connect

O código gerado precisa de um local para ser executado e uma conexão com sua loja. Esse estágio integra tudo — hospedar o código no App Builder, conectá-lo à sua instância do Adobe Commerce e vincular um repositório do GitHub — antes que o recurso seja ativado.

## Para quem é este vídeo?

* Desenvolvedores do Commerce
* Arquitetos de soluções
* Engenheiros de back-end

## Conteúdo de vídeo

* Criar um projeto e um espaço de trabalho do App Builder para hospedar o código criado pelo agente do desenvolvedor
* Observar o suporte do agente no projeto e destacar itens pendentes de configuração
* Adicionar a credencial da API do Adobe Commerce as a Cloud Service necessária no console do desenvolvedor
* Conexão do código a uma instância específica do Adobe Commerce Cloud Service
* Para armazenar e criar a versão do código, vincule um repositório GitHub
