# Configurar credenciais de origem para a Ferramenta de Migração de Dados em Massa

Defina a URL da instância de origem e as credenciais de autenticação no arquivo `.env` antes de executar a Ferramenta de Migração de Dados em Massa. As etapas de autenticação diferem ligeiramente, dependendo se o ambiente de origem está no local ou no Adobe Commerce as a Cloud Service (PaaS).

## Para quem é este vídeo?

* Arquiteto de soluções
* Engenheiro de DevOps
* Desenvolvedor de backend

## Conteúdo de vídeo

* Defina a URL da instância de origem e as URLs REST e GraphQL no arquivo `.env`.
* Recupere ou crie chaves de integração de **Sistema** > **Extensões** > **Integrações** no Administrador do Adobe Commerce.
* Para gerar os quatro tokens necessários, ative a integração.
* Recupere o token da CLI da Magento de account.magento.cloud se a sua fonte for o Adobe Commerce as a Cloud Service (PaaS).
