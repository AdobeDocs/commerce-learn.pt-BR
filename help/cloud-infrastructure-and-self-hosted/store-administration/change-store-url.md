# Alterar uma URL de loja

Cada site em uma instalação do Adobe Commerce ou do Magento Open Source tem um URL de base para a loja e outro URL para o administrador. Este vídeo mostra como alterar a URL base da sua loja.

## Para quem é este vídeo?

* Administradores de armazenamento
* Gerentes de sites
