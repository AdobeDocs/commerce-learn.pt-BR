# Utilização do Adobe Experience League para criar um tíquete de suporte

Saiba como criar um tíquete de suporte no Adobe Experience League para o Adobe Commerce.

## Para quem é este vídeo?

* Pessoas que podem criar solicitações de suporte para o Adobe Commerce na Adobe Experience League

## Conteúdo de vídeo {#video-content}

* Saiba como fazer logon na Adobe Experience League
* Saiba mais sobre os elementos de formulário dinâmicos ao criar um novo tíquete de suporte
* Saiba como os artigos recomendados mudam, dependendo de quais informações foram usadas no formulário
* Como o texto de espaço reservado encontrado nos campos de formulário ajuda a entender o tipo de informações necessárias para uma boa solicitação de suporte
